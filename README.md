This is a complete, runnable Python game that:                                                                                                                                                                      

 1 Creates a window with a fly-catching game                                                                                                                                                                        
 2 Spawns flies that move around the screen                                                                                                                                                                         
 3 Flies buzz and bounce off walls                                                                                                                                                                                  
 4 When you tap/click on a fly, it dies and disappears                                                                                                                                                              
 5 You get points for each fly caught                                                                                                                                                                               
 6 Uses simple colored circles as placeholder images (since we can't download from internet)                                                                                                                        

To run this game:                                                                                                                                                                                                   

 1 Make sure you have Python installed                                                                                                                                                                              
 2 Install Pygame: pip install pygame                                                                                                                                                                               
 3 Save the code in a file named fly_catcher.py                                                                                                                                                                     
 4 Run it with: python fly_catcher.py                                                                                                                                                                               

The game features:                                                                                                                                                                                                  

 • Touch-based interaction (click to catch flies)                                                                                                                                                                   
 • Score tracking                                                                                                                                                                                                   
 • Visual feedback when flies are caught                                                                                                                                                                            
 • Flies that move realistically around the screen                                                                                                                                                                  
 • Simple but effective visual design
